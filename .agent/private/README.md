# Private Folder

This is an ignored compatibility boundary for isolated local notes. It is not the current editorial
source of truth.

Active private source packs, evidence, drafts and analysis live in the independently versioned,
ignored repository at `.agent/reference-local/editorial-private/`. Read that repository's README
for local routing. Never copy its remote, commit identifiers or content into the public parent.

## Rules

1. **Never commit content that reveals psychological vulnerabilities or excess PII to version control.** This includes plan files, commit messages, and code comments.
2. **Third-party individuals must not be named in version-controlled files without explicit consent.**
3. **Biographical details that narrow physical location beyond "UK" require explicit approval.**

See [privacy.md](../directives/privacy.md) and
[private-editorial-workspace.md](../reference/private-editorial-workspace.md).
