# Continuity, memory and knowledge flow

The research home for the estate's learning loop: how observations on the
napkin become distilled lessons, how lessons graduate into permanent homes,
and what a historical napkin synthesis finds when it re-reads the archive.

The `consolidate-docs` skill writes its synthesis reports here as
`historical-napkin-synthesis-YYYY-MM-DD.md` before it mutates doctrine, so
the reasoning behind a graduation is a record and not a commit message. The
first synthesis in this repository is the owner-scheduled 57-lesson pass over
the archived napkin (see `.agent/memory/operational/repo-continuity.md`).

The lineage's own syntheses (five historical passes, a longitudinal review and
a discovery pass, 2026-05 to 2026-09) stay at the lineage pin `e477e62f7`
under this same path; they describe the lineage's napkins, not this estate's,
and are re-importable when a synthesis here wants them as a baseline.

Related doctrine: `.agent/memory/README.md` (the three memory modes),
`.agent/memory/operational/ephemeral-to-permanent-homing.md` and
`.agent/memory/operational/pending-graduations.md`.
