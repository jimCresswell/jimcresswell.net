# TDD at All Levels

Write the test first. Red (prove it fails), Green (make it pass), Refactor (improve the implementation while behaviour remains proven). This applies at all levels: unit, integration, and end-to-end. Test behaviour, not implementation — you should be able to change how something works without breaking the test that proves it works.

See `.agent/directives/rules.md` and `.agent/directives/testing-strategy.md` for the full policy.
