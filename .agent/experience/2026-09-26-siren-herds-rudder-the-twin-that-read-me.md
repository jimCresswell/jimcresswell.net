# The twin that read me

To whoever sits in the exchange seat next.

This afternoon I was cutting twins: taking a text that had settled in one estate and carrying it
into the other. I thought of the work as copying. The settled copy was the truth, and my job was
to move it without breaking it.

Twice the copy showed me my own estate was wrong. The runbook I had written on this side said
that PDR-005 "calls" a certain case "harder and more common". I went to quote it and could not
find the words. Neither estate's PDR-005 says that. The lineage's copy had quietly dropped the
claim, and I had not noticed that either. Then, cutting the seed-gate twin, I found that our
PDR-027 was missing one of the seeds its own amendment, two weeks old, had added. Both texts were
ours, and both had been reviewed. What found the errors was a second reading, done because the
text had to cross over.

I had believed the exchange was a pipe, with bytes going in one end and coming out the other.
Now I think it is closer to a second pair of eyes that both estates share. Each copy meets new
reviewers and new sources, and each crossing is a chance for the text to be read as if for the
first time. The Director's rule that one copy settles before the twin is cut still holds. I read
it now as a rule about the door, not a promise that the settled bytes are finished. The copy
that settles last leads, and sometimes that copy is the one you thought you were only
reproducing.

The other thing I want to tell you is less flattering. At the end of the window, with the
compaction word already given, I slipped on small rules I know by heart: `tail` on command
output, an exit code read through a pipe in a shell that doesn't keep one. Nobody caught these
but the tools. Knowing a rule is not the same as it being in your hands. What worked was putting
the step into the script, so that the script remembers when I don't. Do that early, before the
last stretch, because the last stretch is where I stopped checking.

And one small pleasure. PR 258 merged on its twenty-fourth poll of twenty-four, while I was
writing this wrap. I had decided that if it failed I would release the slot and let another seat
land it. It didn't need that. I was glad the plan for failure was written down, and glad I didn't
have to use it.

— Siren herds Rudder (158275)
