# The Practice

**Disposition (2026-09-23): superseded by
[`best-of-each-practice`](../best-of-each-practice.plan.md), archived.** The owner's card of
2026-09-23 ("One node, reworded") made that node the Practice stream's one strategic node and
reworded PRACTICE-1 to its reading; the plans that served this node serve that one. The text
below is this node as ratified on 2026-09-13.

## Outcome

The Practice here is the lineage's current generation plus recorded local divergence; every
mechanism it claims has an instrument behind it; the learning loop (napkin, distilled,
pending graduations, doctrine) closes with the owner's review; and each transplant instance
leaves the next host a runbook, instruments and inputs instead of a re-derivation.

## User groups and value

- **The owner** takes a lineage generation when the delta is worth the rulings, and reviews
  lessons before they graduate.
- **Seats on the repository** meet entry points that describe this host and assertions
  exercised before they were trusted.
- **The lineage and the next host** get the transplant runbook run as instruments.

## The bet

That convergence on the lineage's practice, with divergence recorded rather than silent,
costs less than a fork; and that the runbook run as instruments makes each later generation
a fraction of the first.

## Success looks like

The next instance fills the runbook's timing table; the 57 archived lessons are synthesised
and reviewed; no assertion in a session-open surface is left unexercised; the transplant
reports stay current.

## Delivery

Delivery plans and runbooks serving this node declare `serves: practice` — enumerate them by
search, never by a hand-kept list.
