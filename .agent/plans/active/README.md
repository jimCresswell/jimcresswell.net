# Active plan

The **currently active** execution plan lives in this **folder** as a normal markdown plan file — not as a separate pointer file.

**Right now:** [personal-knowledge-graph-source-of-truth-design.plan.md](personal-knowledge-graph-source-of-truth-design.plan.md) (Track B — graph-backed source-of-truth design).

## When focus shifts

1. **Move** the finished plan out of `active/` (e.g. to `complete/` or back under `current/` if it still belongs in the in-flight stack — see `roadmap.md`).
2. **Move** the new primary plan **into** `active/` (single plan file in this directory).
3. Update **this README** so the first paragraph names the new file and one-line context.
4. Reconcile **`.agent/plans/roadmap.md`** and parent-plan tables in the same pass.

`../current/` still holds other in-flight plans; only the **primary** focus file lives here.
