# Explorations

Explorations sit between transient session notes and durable decision records.
Use this tier for design-space work that is still being compared, tested, or
challenged before it is ready to become an ADR, PDR, EDR, or permanent
reference doc.

## Use this directory for

- competing approaches and trade-off analysis
- partially-proven ideas that need more evidence
- synthesis notes that are too durable for the napkin but not decision-ready

## Do not use this directory for

- settled decisions
- session handoff notes
- platform adapter instructions

Graduate explorations once the decision is stable.
