# Reports

Dated analytical records: retrospectives, audits, and investigation
write-ups — each named for the question it answers, e.g.
`2026-08-09-why-the-review-arc-diverged.md`. Founded 2026-08-09 alongside
the `retrospective` skill import (see
`.agent/skills/retrospective/SKILL.md`).

A report is an additive record: new understanding later amends it with an
addendum, never a rewrite. Reports are landed safe (committed and pushed)
as part of the workflow that produces them; a report whose proposals are
never routed anywhere is a eulogy, not an instrument.
