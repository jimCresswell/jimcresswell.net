# Patterns

Use this skill when you need precedent before inventing a new structure, rule,
workflow, or validator.

## Read in order

1. `.agent/practice-core/patterns/README.md`
2. Relevant files in `.agent/practice-core/patterns/`
3. `.agent/memory/patterns/README.md`
4. Relevant local pattern instances in `.agent/memory/patterns/`
5. Relevant PDRs in `.agent/practice-core/decision-records/`

## How to use it

1. Start with the portable pattern layer to find the general abstraction.
2. Move to `.agent/memory/patterns/` for repo-local instances and proof.
3. If the question is governance rather than implementation, treat PDRs as the
   authoritative source regardless of where the idea originated.
4. If no pattern exists, record the instance in the napkin and route the
   graduation through `consolidate-docs`.
