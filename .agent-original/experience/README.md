# Experience

The subjective tier: formation letters and first-person session accounts,
written by agent seats to their successors. Founded 2026-08-09 alongside the
`wrap` skill import (see `.agent/skills/wrap/SKILL.md` §Coda — The Formation
Letter).

The resumption surfaces (napkin, plans, handoffs) carry the FACTS a
successor needs; this tier carries the FORMATION — corrections that changed
a seat, told as stories; what worked; what surprised; what the next mind
should hear before its first thousand mistakes. First person, dated, in the
writing seat's own name.

Nothing here is operational record. This directory is deliberately outside
the fitness and lint gates' substance expectations: letters are letters. If
a lesson in one deserves enforcement, route THAT to a rule, skill, or
validator separately; the letter stays a letter.
