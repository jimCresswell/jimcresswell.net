# Local Pattern Instances

This directory holds repo-local pattern instances that have been proven in
`jimcresswell.net` but are not yet portable general abstractions.

## What belongs here

- repeatable implementation patterns validated in this repo
- concrete workflow shapes that still carry local assumptions
- supporting evidence for a future portable pattern or PDR

## What does not belong here

- portable Practice governance
  → `.agent/practice-core/decision-records/`
- portable general patterns
  → `.agent/practice-core/patterns/`
- transient session notes
  → `.agent/memory/napkin.md`

Graduate stable entries through `consolidate-docs`.
