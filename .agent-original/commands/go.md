# Resume the Work

Use this when you need to continue from the repo's live continuity surfaces
without re-planning from scratch.

## Process

1. Ground first via `start-right-quick` or `start-right-thorough`.
2. Read `.agent/prompts/session-continuation.prompt.md` if it exists and is
   relevant to the active workstream.
3. Re-read the active plan's current phase and next unfinished task list.
4. Summarise the current state of play, challenge assumptions, and identify the
   next concrete step before editing.
5. If the plan, prompt, and roadmap disagree, reconcile them before coding.

## Success

You can name the next concrete task, the proofs that are still fresh, and the
first command or edit that should happen next.
